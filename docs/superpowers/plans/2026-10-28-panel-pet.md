- Pet is local QML pixel art, with no downloads or image-generation dependency.
- No new raw agent data, permission approvals, telemetry, or global keyboard shortcuts.
- Preserve Qoder/Claude config; no hook installation without user opt-in.
- Use native Plasma panel and theme; preserve existing widgets, colorizer and layout.
- Reduced motion keeps state readable and pet static; pause animation when hidden.

- Pixel cat remains visible at actual panel heights, no rich-text interpretation.
