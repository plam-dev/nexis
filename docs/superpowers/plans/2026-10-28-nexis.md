# NEXIS Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task by task. The user has requested execution of the supplied technical spec in this folder.

**Goal:** Build the native KDE island described in NEXIS_TECHNICAL_SPEC.md, matching the installed Orchis Dark theme.
**Architecture:** A Qt6 C++ process owns a bounded local event collector, session registry, read-only D-Bus snapshots, MPRIS and system adapters. QML renders the capsule and activity center. A separate small C++ bridge sanitizes vendor stdin before sending to the collector; Python's standard library handles reversible settings merges.
**Tech stack:** C++17, Qt6 Quick/Controls/DBus/Network/Test, optional LayerShellQt, Python3 standard library.
**Spec:** NEXIS_TECHNICAL_SPEC.md

## Global constraints
- Same UID socket clients; runtime directory 0700, socket 0600; no TCP.
- No prompts, arguments, results, transcripts, environment, or absolute target paths cross the bridge.
- Bridge always exits zero with no stdout; bound stdin, connection and write deadlines.
- Stop means turn complete; no timeout may claim completion.
- No global shortcut or hook installation without explicit user action; never grant permissions.
- Real integrations only in normal mode; preview fixtures only with --demo.
- Use KDE palette/font/icons automatically; reduced motion and no exclusive screen zone.

## Review focus
- A writer stalls mid-JSON: bounded buffering, deadline and connection count.
- Concurrent or malformed settings edits: lock, backup, atomic replace, preserve unrelated hooks.
- Providers restart or properties invalidate: rediscover without controlling the wrong player.
- Missing IDs, duplicate or old events: namespace sessions, mark uncertain and ignore replay.
- Compositor lacks an API: disclose degraded capability rather than claim success.
